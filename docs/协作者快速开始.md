# 协作者快速开始

这份文档只保留最短路径，适合第一次从 GitHub 下载项目的协作者。

## 一句话版本

按顺序运行：

```text
1. bootstrap_windows.bat
2. 填 .env
3. build_behavior_data.bat
4. build_knowledge_base.bat
5. start_windows.bat
```

## 第一步：bootstrap

执行：

```bat
bootstrap_windows.bat
```

它会自动：

- 创建 `.venv`
- 安装依赖
- 生成 `.env`
- 下载完整演示所需模型

## 第二步：改 `.env`

至少把下面项改成真实值：

```env
LLM_API_KEY=your_real_key
LLM_API_BASE=https://api.openai.com/v1
```

## 第三步：构建行为分析数据库

执行：

```bat
build_behavior_data.bat
```

## 第四步：构建景区知识库

执行：

```bat
build_knowledge_base.bat
```

## 第五步：启动

执行：

```bat
start_windows.bat
```

## 访问地址

前台：

```text
http://localhost:8000/
```

后台：

```text
http://localhost:8000/admin
```

默认管理员：

```text
admin / admin123
```

## 必须知道的事

- TTS 方案固定为 `edge-tts`
- `edge-tts` 运行时要联网
- 完整模式模型体积较大，建议预留 18GB 到 20GB+
- 前端页面也依赖 CDN，建议保持联网

## 如果失败

优先按这个顺序重来：

```text
bootstrap_windows.bat
build_behavior_data.bat
build_knowledge_base.bat
start_windows.bat
```

如果还是不行，查看 `start_windows.bat` 里预检输出的 JSON 错误信息。
