版本日期：【填写提交日期】

## 1. 系统简介

本系统面向景区导览服务场景，提供游客交互端和管理后台两类入口。游客可以通过文本或语音与 AI 数字人导游互动，获得景点事实问答、个性化路线推荐和弱 GPS 场景下的问路辅助；管理人员可以在后台查看游客关注点、推荐标签、满意度趋势、知识库健康度、统一评测结果，并配置数字人头像、音色和画质模式。

系统核心能力包括：

- 基于 DOCX 景区资料的本地知识库问答。
- 基于 Excel 游客行为数据的统计分析。
- `FACT / ANALYTICS / RECOMMEND` 三类业务路由。
- Whisper 语音识别、Edge-TTS 语音合成、SoulX-FlashHead 数字人视频生成。
- React + Vite 游客端和管理后台。
- FastAPI 后端和统一 CLI 工程入口。

## 2. 环境要求

### 2.1 推荐硬件

| 项目 | 推荐配置 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| CPU | 8 核及以上 |
| 内存 | 16 GB 及以上 |
| GPU | NVIDIA GPU，建议 8 GB 显存及以上 |
| 磁盘 | 30 GB 以上可用空间 |

说明：无 GPU 时，问答、知识库和后台能力仍可运行，但数字人视频生成体验会明显下降。

### 2.2 软件依赖

项目通过 `environment.yml` 和脚本统一管理依赖。主要组件包括：

- Python / Conda
- Node.js
- FastAPI
- React + Vite
- ChromaDB
- SQLite
- Whisper
- Edge-TTS
- SoulX-FlashHead

## 3. 首次部署

在项目根目录 `D:\Human` 下执行：

```bat
bootstrap_windows.bat
```

脚本会自动完成：

- 创建或修复 `D:\Human\env`
- 安装 Conda 和 pip 依赖
- 安装 GPU 版 PyTorch
- 安装 Whisper
- 下载项目所需模型
- 执行运行时健康检查

如需手动使用统一 CLI，命令格式为：

```bat
conda run -p "D:/Human/env" python -m app.cli <command>
```

## 4. 数据构建

### 4.1 构建游客行为数据

```bat
build_behavior_data.bat
```

该脚本会读取 `data/raw_sql_data/` 下的 Excel 数据，生成游客行为分析用 SQLite 数据库。

### 4.2 构建景区知识库

```bat
build_knowledge_base.bat
```

该脚本会读取 `data/knowledge_base/` 下的 DOCX 资料，构建景区结构化事实表和向量知识库。

## 5. 构建前端

```bat
conda run -p "D:/Human/env" python -m app.cli build-frontend
```

构建完成后，前端静态文件会输出到后端可访问目录，便于通过统一后端入口访问游客端、登录页和管理后台。

## 6. 启动系统


## 7. 游客端使用流程

### 7.1 文本问答

1. 登录后进入游客前台。
2. 在输入框中输入景区问题。
3. 点击“发送”。
4. 系统展示回答、数据源标签和数字人视频。

推荐测试问题：

```text
灵山梵宫为什么被称为佛教艺术的卢浮宫？
```

### 7.2 个性化路线推荐

游客端提供三条演示路线入口：

- 历史文化
- 亲子家庭
- 自然风光

点击任一入口后，系统会生成路线节点、预计时长、讲解重点和游客行为依据。

### 7.3 语音交互

1. 允许浏览器使用麦克风。
2. 按住“语音提问”按钮说话。
3. 松开按钮后上传音频。
4. 后端通过 Whisper 识别语音，再生成文本回答、语音和数字人视频。

### 7.4 弱 GPS 多轮问路

1. 在游客端开启“弱 GPS 模式”。
2. 输入类似问题：

```text
我现在定位不准，只看到一座桥和很长的步道，下一站怎么走？
```

3. 系统会根据地标描述进行候选位置判断，并通过多轮澄清辅助游客确定当前位置。

## 8. 管理后台使用流程

### 8.1 数据驾驶舱

后台展示：

- 累计互动量
- 当日互动量
- 平均响应耗时
- 知识文档数
- 统一评测得分
- 意图分布
- 推荐标签分布
- 满意度趋势
- 游客关注焦点

### 8.2 评测与健康度

后台显示：

- 知识库是否就绪
- 行为库是否就绪
- 统一评测总分
- 失败样例数量
- 数据重建命令

### 8.3 知识库管理

后台展示已接入的 DOCX 知识文档和 Excel 行为数据文件，包括文件名、大小和更新时间。当前版本以“可维护状态展示 + 本地构建命令”为主，保证评委能看到知识库管理链路。

### 8.4 数字人配置

后台支持：

- 音色选择
- 音色试听
- 默认头像上传
- 数字人画质模式切换

数字人画质模式：

- `省显存`：优先降低显存占用。
- `高质量`：优先提升演示观感，推荐答辩录屏时使用。

## 10. 常见问题

### 10.1 语音识别失败

检查：

- 浏览器麦克风权限是否开启。
- `/api/v1/interact/audio` 是否可访问。
- `imageio-ffmpeg` 自带 ffmpeg 是否存在。

### 10.2 数字人视频没有生成

检查：

- 返回体中是否包含 `video_stream_url`。
- `SoulX-FlashHead/data/temp/` 下是否生成 `*_video.mp4`。
- GPU 显存是否足够。
- 后台是否切换到适合当前机器的数字人模式。

### 10.3 后台图表为空

先运行：

```bat
conda run -p "D:/Human/env" python -m app.cli seed-demo-logs --reset
```

然后刷新管理后台。

### 10.4 统一评测出现 telemetry 警告

如果出现类似日志：

```text
Failed to send telemetry event ...
```

该警告来自 ChromaDB telemetry，不影响知识库检索、评测结果或系统运行。
