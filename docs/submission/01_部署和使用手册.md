# 部署和使用手册

项目名称：灵山胜境导览服务 AI 数字人系统

## 1. 系统简介

本系统面向景区导览服务场景，提供游客前台和管理后台两类入口。游客可以通过文本或语音与 AI 数字人交互，获得景区事实问答、深资料讲解、游客行为分析结果和个性化路线推荐；管理员可以查看知识库状态、行为分析、统一评测结果、失败样例和数字人配置。

当前版本已经升级为 planner-first 的 RAG+SQL 架构：

- 景区结构化事实优先回答事实问题。
- semantic SQL 优先回答行为分析问题。
- hybrid RAG 处理非结构化深资料。
- route planner 输出路线节点、时长、依据和讲解重点。
- 所有结果统一返回结构化响应契约。

## 2. 环境要求

### 2.1 推荐硬件

| 项目 | 建议配置 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| CPU | 8 核及以上 |
| 内存 | 16 GB 及以上 |
| GPU | NVIDIA GPU，建议 8 GB 显存及以上 |
| 磁盘 | 30 GB 以上可用空间 |

说明：无 GPU 时，前后台和问答链路仍可运行，但数字人视频体验会明显下降。

### 2.2 核心依赖

- Python / Conda
- Node.js
- FastAPI
- React + Vite
- ChromaDB
- SQLite
- Whisper
- Edge-TTS
- SoulX-FlashHead

统一依赖入口为 `environment.yml`。

## 3. 首次部署

在项目根目录 `D:\Human` 执行：

```bat
bootstrap_windows.bat
```

脚本会自动完成：

- 创建或修复 `D:\Human\env`
- 安装 Conda 与 pip 依赖
- 安装 GPU 版 PyTorch
- 安装 Whisper
- 下载项目所需模型
- 执行运行时健康检查

如需使用统一 CLI：

```bat
conda run -p "D:/Human/env" python -m app.cli <command>
```

## 4. 数据构建

### 4.1 构建游客行为库

```bat
build_behavior_data.bat
```

该脚本会读取 `data/raw_sql_data/` 下的 Excel 数据，并生成 SQLite 行为分析库。

### 4.2 构建景区知识库

```bat
build_knowledge_base.bat
```

该脚本会读取 `data/knowledge_base/` 下的 DOCX 资料，并同时生成：

- 结构化景区事实
- 向量知识库
- hybrid RAG 所需检索索引

## 5. 构建前端

```bat
conda run -p "D:/Human/env" python -m app.cli build-frontend
```

构建完成后，游客前台、登录页与管理后台均可通过统一后端入口访问。

```text
admin / admin123
```

## 7. 当前接口与响应说明

本次升级后，问答接口统一返回更丰富的 `rag_metadata`。核心响应契约字段包括：

- `answer`
- `response_kind`
- `plan`
- `evidence`
- `refusal`
- `warnings`
- `observability`

详细说明见：

- `docs/rag_response_contract.md`

这意味着前端、后台和评测工具都可以直接消费统一的结构化结果，而不必从自然语言答案中猜测执行过程。

## 8. 日志与后台观测

日志服务已经持久化以下结构化字段：

- `plan_json`
- `evidence_json`
- `refusal_json`
- `warnings_json`
- `observability_json`

这些字段用于：

- 后台失败样例回放
- 调试具体 planner 决策
- 评测与线上行为对齐
- 后续策略回归分析

## 10. 使用流程

### 10.1 游客前台

1. 登录后进入游客前台。
2. 输入景区问题，或点击语音输入提问。
3. 系统根据 planner 决策进入结构化事实、semantic SQL、hybrid RAG 或路线规划链路。
4. 前台展示答案、来源依据、生成状态与数字人视频。

### 10.2 管理后台

1. 进入后台首页查看互动量、意图分布、满意度趋势与热点问题。
2. 查看知识库状态、行为库状态和统一评测结果。
3. 通过失败样例和结构化日志检查 planner 决策与拒答边界。
4. 在数字人配置区切换音色、头像和画质模式。

## 12. 常见问题

### 12.1 语音识别失败

检查：

- 浏览器麦克风权限是否开启
- `/api/v1/interact/audio` 是否可访问
- `imageio-ffmpeg` 自带 ffmpeg 是否存在

### 12.2 数字人视频未生成

检查：

- 返回体中是否包含 `video_stream_url`
- `SoulX-FlashHead/data/temp/` 下是否生成 `*_video.mp4`
- GPU 显存是否足够
- 当前画质模式是否适合机器配置

### 12.3 后台图表为空

先执行：

```bat
conda run -p "D:/Human/env" python -m app.cli seed-demo-logs --reset
```

### 12.4 telemetry 警告

如出现类似日志：

```text
Failed to send telemetry event ...
```

这是 Chroma 的遥测告警，不影响检索、问答或评测结果。
