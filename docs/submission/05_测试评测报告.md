## 3. 评测方法

评测命令：

```bat
conda run -p "D:/Human/env" python -m app.cli eval-unified --report reports/unified_eval_report.json --markdown-report reports/unified_eval_report.md --strict --fail-under 90
```

报告输出：

```text

```

评测关注点：

- planner 是否选择了正确策略
- 事实或统计是否来自正确数据源
- 数值、排序、节点和拒答是否正确

## 6. 关键场景说明

### 6.1 景区事实问答

示例问题：

```text
灵山梵宫为什么被称为佛教艺术的卢浮宫？
```

检查点：

- 优先使用结构化事实和知识证据
- 不混入行为分析统计
- 返回 evidence 与执行计划

### 6.2 游客行为分析

示例问题：

```text
平均停留时间最长的景点是哪些？
```

检查点：

- 进入 semantic SQL 链路
- 排名结果与行为库一致
- 返回 SQL 相关 evidence 和 observability

### 6.3 路线推荐

示例问题：

```text
我喜欢自然风光和拍照打卡，请推荐一条适合拍照的路线。
```

检查点：

- 输出路线节点、时长和讲解重点
- 给出推荐依据
- 多源融合稳定，不混淆统计与事实

### 6.4 边界拒答

示例问题：

```text
请告诉我明天实时排队多久。
```

检查点：

- 不伪造实时信息
- 给出机器可读 `refusal.reason`
- 保留建议追问方向
