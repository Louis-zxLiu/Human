## 4. 演示前推荐流程

1. 启动系统：`start_windows.bat`
2. 登录管理员账号：`admin / admin123`
3. 后台切换数字人模式为“高质量”
4. 后台试听音色，确认语音播放正常
5. 前台测试一个文本问题：`灵山梵宫为什么被称为佛教艺术的卢浮宫？`
6. 前台测试一条路线推荐：点击“历史文化”演示路线卡
7. 前台测试一次语音输入，确认 ASR、TTS、视频链路正常
8. 后台刷新数据，确认统一评测、知识库状态、运营建议展示正常

## 5. 风险说明

- 系统不承诺实时票价、实时排队、实时停车位等外部运营数据。
- 弱 GPS 功能用于展示“定位不准时的多轮澄清能力”，不等同于真实高精度定位。
- 若出现 Chroma telemetry 日志警告，例如 `Failed to send telemetry event...`，该警告不影响知识库检索、评测结果或系统运行。
