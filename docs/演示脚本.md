# 演示脚本

## 演示顺序

1. 事实问答
2. 个性化推荐
3. 弱 GPS 问路
4. 后台分析看板

## 1. 事实问答

### 建议问题

- 灵山梵宫开放时间是什么？
- 灵山大佛在哪里？
- 九龙灌浴有什么看点？

### 讲解重点

- 说明事实题只走灵山景区知识层。
- 强调不会用跨景区行为分析数据回答景区事实。

## 2. 个性化推荐

### 建议问题

- 给我推荐一条适合历史爱好者的路线。
- 我喜欢自然风光，怎么逛比较合适？

### 讲解重点

- 展示推荐路线、适合原因、预计游览时长、讲解重点和行为分析补充。
- 说明推荐是“景区事实 + 游客行为分析”的组合，而不是纯大模型自由生成。

## 3. 弱 GPS 问路

### 开启方式

- 前端打开 `GPS 信号极弱` 开关。

### 建议对话

1. 用户：我现在在哪，怎么去梵宫？
2. 系统：先追问附近地标。
3. 用户：我旁边能看到大佛和一片大广场。
4. 系统：判断可能在灵山大佛附近，并给出去梵宫的后续建议。

### 讲解重点

- 强调不是直接硬答，而是通过多轮交互反向定位。
- 说明这属于真实景区复杂场景加分项。

## 4. 后台分析看板

### 展示内容

- 当日/累计交互量
- 游客意图分布
- 情感趋势
- 热门分析问题
- 热门景点偏好
- 推荐标签分布
- 最近失败/拒答样例
- 数据状态卡片

### 讲解重点

- 后台不仅能看总量，还能看推荐效果和问题分布。
- 失败样例可以帮助后续继续优化知识库与问答能力。
